# Security

This repository serves a static website and public PDFs. There are no funds at risk here.

- **Contact:** security@zkbtc.com
- Do not open a public GitHub issue for an unpatched soundness issue in the zkBTC design. Report those to [zk-BTC/zkbtc](https://github.com/zk-BTC/zkbtc) as described in that repository’s `SECURITY.md`.
- Site issues (open redirect, mixed content, accidental indexing of `/`) may be reported here.
