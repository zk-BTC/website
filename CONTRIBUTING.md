# Contributing

This repository is a static site. Changes land through pull requests into `main`. Do not push directly to `main`.

- Keep `/` a redirect. Do not put the whitepaper body on `/`.
- Keep `/white-paper/` the canonical English paper URL.
- Update both language pages when you change shared copy.
- When the paper in zk-coins/zkbtc changes, replace `files/*.pdf` in the same pull request as any viewer-copy change.
- Signed commits. Public-repo text is English.

The site has no application code and no test suite. Check pages locally with any static file server before opening a pull request.
